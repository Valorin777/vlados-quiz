# Кто лучше знает Владоса

Викторина, которую я сделал другу на день рождения. Играли на вечеринке:
на телевизоре идёт шоу, гости заходят с телефонов по QR-коду, фоткаются
на аватарку и отвечают на вопросы про именинника. Владос отвечает вместе
со всеми, но вне конкурса, а в финале видно, кто знает его лучше
всех и знает ли он сам себя.

## Экраны

- **ТВ** — большой экран: лобби с аватарками, вопросы, таймер, разбор ответов, таблица, финал
- **Телефон** — вход, ответы, реакции
- **Админка** — вопросы, настройки, репетиция и автопилот, который ведёт шоу сам

Состояние игры живёт в Firestore, все экраны подписаны на него в реальном
времени. Кто что может писать, ограничивают правила Firestore,
они генерируются из шаблона `firestore.rules.tmpl`.

## Стек

React 19, TypeScript, Vite, zustand, GSAP и motion для анимаций,
Firebase (Auth + Firestore), Vitest и Playwright для тестов.
Хостинг на GitHub Pages.

## Запуск

```bash
npm install
npm run dev:app     # локально
npm test            # юнит-тесты
npm run build       # сборка в dist/app
```

Конфиг Firebase лежит в `shared/fbconfig.json`. Это публичный web-конфиг,
поэтому он в репозитории. Для своего проекта подставь свой и выкати правила
(`npm run rules:deploy:dev`).

Видео для сюрприза и финала в репозиторий не положил, там личное.
Чтобы всё работало, добавь свои `surprise.mp4`, `finale.mp4` и постеры
`surprise-poster.jpg`, `finale-poster.jpg` в `app/public/`.
